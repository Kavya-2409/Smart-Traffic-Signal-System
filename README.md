🚦 Smart Traffic Signal System (Java)
📌 Overview

A Java project that simulates an intelligent traffic control system based on real-time vehicle density and emergency situations.

⚙️ Features
Dynamic traffic signal control based on vehicle count
Priority for busiest road
Emergency vehicle handling mode
Traffic level classification (Low/Medium/High)
Custom exception handling
🧠 Logic
Highest vehicle road gets GREEN signal
Second priority road is identified
Emergency vehicle overrides normal flow
🛠 Tech Used
Java (Core Java)
OOP Concepts
Exception Handling
▶️ How to Run
Compile:
javac SmartTrafficSignal.java
Run:
java SmartTrafficSignal
📂 Project Structure
Road Class – stores road data
TrafficSystem Class – core logic
EmergencyVehicle Class – handles emergency mode
TrafficException – custom error handling
Main Class – user interaction
